# PROJECT: Md Danish Alam — Top 1% Portfolio

A premium, recruiter-ready portfolio for a Data Analyst (AI & Automation Focus). Built with Next.js, AMOLED black aesthetics, and immersive 3D/Glassmorphism.

## Vision
To create the most visually stunning and professional portfolio in the analytics domain, demonstrating technical mastery of AI, automation, and data visualization through an Apple-inspired futuristic interface.

## Core Identity
- **Name**: Md Danish Alam
- **Role**: Data Analyst (AI & Automation)
- **Aesthetic**: AMOLED Cyberpunk-Glass (Pure black, high-end blurs, neon accents)

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4, Framer Motion
- **3D**: Three.js, React Three Fiber
- **Motion**: Lenis (Smooth Scroll)
- **State**: Centralized in `data/portfolio.ts`

## Requirements Summary
- [ ] Responsive design (Mobile/Desktop)
- [ ] High-performance 3D background (Planetary Orb + Starfield)
- [ ] Premium Custom Cursor with trailing motion
- [ ] 7 Core Sections (Hero, About, Skills, Impact, Experience, Certifications, Contact)
- [ ] Recruiter-friendly content (No over-claims)
- [ ] Smooth momentum scrolling
