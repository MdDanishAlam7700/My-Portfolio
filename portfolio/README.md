# Md Danish Alam — Premium Portfolio

A top 1% recruiter-ready portfolio website for a **Data Analyst (AI & Automation Focus)**. Built with a focus on Apple-inspired glassmorphism, subtle cyberpunk aesthetics, and high-performance interactivity.

## 🚀 Technical Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) (Framer Motion)
- **3D Graphics**: [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/) & [Three.js](https://threejs.org/)
- **Typography**: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Scrolling**: [Lenis](https://lenis.darkroom.engineering/) (Smooth Scroll)

## ✨ Key Features

- **Apple-Inspired UI**: Premium glassmorphism with soft blurs, layered surfaces, and high-contrast typography.
- **Subtle Cyberpunk Aesthetic**: Elegant neon accents (Cyan & Violet) with animated gradient mesh backgrounds.
- **Global Background System**: A unified background layer with 3D particle fields and parallax effects that persist across all sections.
- **Interactive 3D Hero**: A reactive glass orb built with Three.js that responds to mouse movement.
- **Data-Driven Architecture**: Centralized `data/portfolio.ts` for easy maintenance and identity consistency.
- **Recruiter-Friendly Content**: Grounded in real-world experience at **5 Data INC**, **AI Variant**, and **Flipkart**, with no exaggerated claims.

## 📁 Project Structure

```bash
├── app/                  # Next.js App Router (Layout, Providers, Home)
├── components/           # Atomic UI & Section Components
│   ├── layout/           # Navbar, Footer, Custom Cursor
│   ├── sections/         # The 7 core portfolio sections
│   └── ui/               # Reusable GlassCards, Buttons, and 3D Orbs
├── data/                 # Centralized portfolio data
├── lib/                  # Utility functions (cn helper)
└── public/               # Static assets (Resume.pdf, Favicon)
```

## 🛠️ Getting Started

1. **Clone and Install**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
